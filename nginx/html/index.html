Go Bank Service API

REST API банковского сервиса на Go: пользователи, счета, карты, переводы, кредиты, аналитика, MFA, audit logs, idempotency и интеграция с ЦБ РФ.

Быстрая проверка

GET /health

Документация

Полное описание проекта, env-переменные, запуск и сценарии тестирования: README.md на GitHub.

Короткая ссылка с этого сервера: /docs.

Тестовый администратор

Первый зарегистрированный пользователь становится администратором. Для проверки admin-сценариев уже зарегистрирован следующий тестовый пользователь: 

{
  "login": "test@example.com",
  "password": "password123"
}

Авторизация

Authorization: Bearer <token>

Токен получается через POST /login. После повторного login старый токен этого же пользователя становится недействительным.

MFA

MFA требуется для критических операций:

  • withdraw
  • transfer
  • card_payment
  • card_transfer
  • credit_create

Idempotency-Key

Для финансовых POST-запросов используется заголовок Idempotency-Key. Повтор того же запроса с тем же ключом не выполнит финансовую операцию второй раз.

Важно

  • Счета и карты закрываются через soft close, без физического удаления из БД.
  • Закрытые или просроченные карты нельзя использовать для оплаты и перевода.
  • HTTP-доступ сделан исключительно для тестового стенда, для production надо делать https
