Go Bank Service API

REST API банковского сервиса на Go: пользователи, счета, карты, переводы, кредиты, аналитика, MFA, audit logs, idempotency и интеграция с ЦБ РФ.

Сделано в рамках семестрового задания по дисциплине "Язык программирования GO".

Стартовая страница оставлена отдельно, а React frontend доступен рядом по адресу /app/.

Адреса на сервере

Landing page:  /

Docs:          /docs

Как тестировать API через test.http

Для серверного стенда используйте baseUrl с префиксом /api: 

@baseUrl = http://SERVER_IP/api

Локально для прямого запуска Go backend можно оставить http://localhost:8080.

Тестовый администратор

Первый зарегистрированный пользователь становится администратором. Для проверки admin-сценариев уже зарегистрирован следующий тестовый пользователь: 

{
  "login": "test@example.com",
  "password": "password123"
}

Основные endpoint-ы API

PublicПубличные

  • GET /api/health
  • POST /api/register
  • POST /api/login

AuthАвторизация

  • GET /api/auth/check
  • POST /api/logout
  • POST /api/mfa/request

AccountsСчета

  • POST /api/accounts
  • GET /api/accounts
  • GET /api/accounts/{accountId}
  • POST /api/accounts/{accountId}/deposit
  • POST /api/accounts/{accountId}/withdraw
  • POST /api/accounts/{accountId}/close
  • GET /api/accounts/{accountId}/predict

CardsКарты

  • POST /api/cards
  • GET /api/cards
  • GET /api/cards/{cardId}
  • POST /api/cards/{cardId}/pay
  • POST /api/cards/{cardId}/transfer
  • POST /api/cards/{cardId}/close

CreditsКредиты

  • POST /api/credits/check
  • POST /api/credits
  • GET /api/credits
  • GET /api/credits/{creditId}
  • GET /api/credits/{creditId}/schedule

OtherДругое

  • POST /api/transfer
  • GET /api/analytics
  • GET /api/rates/key
  • GET /api/notifications/test

AdminАдминистрирование

  • GET /api/admin/users
  • GET /api/admin/logged-in-users
  • POST /api/admin/accounts/{accountId}/block
  • POST /api/admin/accounts/{accountId}/unblock

Важно

  • Для финансовых POST-запросов используется Idempotency-Key.
  • MFA требуется для withdraw, transfer, card payment, card transfer и credit create.
  • HTTP-доступ подходит только для тестового стенда. Для production нужен домен и HTTPS.
