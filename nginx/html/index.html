Go Bank Service API

REST API банковского сервиса на Go: пользователи, счета, карты, переводы, кредиты, аналитика, MFA, audit logs, idempotency и интеграция с ЦБ РФ.

Быстрая проверка

GET /health

Документация

Полное описание проекта, env-переменные, запуск и сценарии тестирования: README.md на GitHub.

Короткая ссылка с этого сервера: /docs.

Авторизация

Authorization: Bearer <token>

Токен получается через POST /login. Первый зарегистрированный пользователь становится администратором.

Основные endpoint-ы

Public
  • POST /register
  • POST /login
  • GET /health
Accounts
  • POST /accounts
  • GET /accounts
  • POST /accounts/{accountId}/deposit
  • POST /accounts/{accountId}/withdraw
Cards
  • POST /cards
  • GET /cards
  • POST /cards/{cardId}/pay
  • POST /cards/{cardId}/transfer
  • POST /cards/{cardId}/close
Credits
  • POST /credits/check
  • POST /credits
  • GET /credits
  • GET /credits/{creditId}/schedule
Other
  • POST /transfer
  • POST /mfa/request
  • GET /analytics
  • GET /rates/key
Admin
  • GET /admin/users
  • GET /admin/logged-in-users
  • POST /admin/accounts/{accountId}/block
  • POST /admin/accounts/{accountId}/unblock

Важно

  • Для финансовых POST-запросов используется Idempotency-Key.
  • MFA требуется для withdraw, transfer, card payment, card transfer и credit create.
  • Доступ к API без HTTPS подходит только для тестового стенда. Для production нужен домен и HTTPS.
